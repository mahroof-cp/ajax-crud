# Laravel CRUD Application

This is a simple Laravel CRUD application built to demonstrate basic application features with a clean and user-friendly interface.

---

## ✨ Features

- List records  
- Create new records  
- Update existing records  
- Delete records  
- File upload support  
- Modal-based forms (Create / Update)  
- Advanced filtering  
- Import data  
- Export data
